SpinRush - free-play slot cabinet (3 games)

Open SpinRush.html in any web browser (double-click it). No install needed.
Fonts load from Google Fonts when online; it still works offline with fallback fonts.

Games: Neon Sevens (25 lines, free spins), Diamond Fire (classic 3-reel),
Gold Rush (243 ways, hold & win). Each pays back about 84% on average.

maths/game_maths.py  - the simulation used to set and verify the payout rates
                       (python3 game_maths.py all 4000000)

Free play only: credits have no cash value and cannot be bought or cashed out.
